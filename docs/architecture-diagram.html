Multi-Agent Chat — Architecture

Hermes-based CLI multi-agent group chat · Unix Domain Socket IPC · Process-isolated Agent runners

Core Components

  • • Orchestrator — REPL + 消息路由 + 进程生命周期
  • • ChatBus — UDS 服务端，select.select() 非阻塞事件循环
  • • Agent Runner — 常驻子进程，120s 超时保护，90s 无心跳 respawn
  • • Hermes Bridge — hermes chat -q 子进程调用封装

Speech Control

  • • 三态机：IDLE → SPEAKING → END
  • • END_MARKER = "我的发言结束。"
  • • 120s 超时兜底，强制打断释放锁
  • • Admin 可打断，@mention 触发自动入队

Memory & State

  • • GBrain — profile 级别记忆，跨会话持久化
  • • session.json — 成员、模式、发言顺序（24h 过期）
  • • 各 profile 独立进程，状态隔离
  • • 退出自动保存，进入检测并恢复
